# Interpretación de las consignas de Bootstrap

En el README se pide elaborar «el siguiente componente» o «la siguiente pantalla», pero no están incluidas las imágenes de referencia. Al revisar el material, no pudimos determinar con certeza el diseño exacto que se esperaba.

| Opción considerada | Ventaja | Limitación |
| --- | --- | --- |
| Copiar un sitio comercial actual | Permite ver una interfaz completa | Agrega funciones y estilos que la consigna no pide; no sabemos si coincide con la referencia |
| Dejar los cuatro ejercicios sin resolver hasta conseguir capturas | Mantiene pendiente la fidelidad visual | No permite practicar ni demostrar Bootstrap |
| Interpretar cada descripción como una maqueta representativa | Practica los componentes y clases pedidos con un alcance acotado | No acredita reproducción exacta de una imagen ausente |

**Elegimos la tercera opción**, por ser la más lógica y viable con el material disponible. Suponemos que la profe se refería a reproducir la estructura visual de estos componentes con Bootstrap:
- **Vuelos:** formulario con origen, destino, fechas, tipo de viaje y pasajeros; resultados y selección local con datos de ejemplo.
- **Timeline tipo Jira:** tareas, estado y barras distribuidas por semanas.
- **Perfil tipo LinkedIn:** portada, avatar, presentación, experiencia, formación y habilidades.
- **Pantalla tipo YouTube:** navegación lateral, buscador, filtros temáticos y rejilla de videos.

Son interpretaciones de la descripción, no copias verificadas de las referencias. Si aparecen las capturas, se puede ajustar la distribución visual conservando la base Bootstrap.

Instagram sí tiene requisitos explícitos: una columna en pantallas pequeñas y tres desde el breakpoint md de Bootstrap (768 px), con imágenes al 100% de cada columna. No confundirlo con el ejercicio CSS de la Unidad 2, que usa el límite de 600/601 px.

Las imágenes de Instagram provienen del material de clase. Las miniaturas SVG son ilustraciones locales; los enlaces llevan a videos citados en las filminas. Bootstrap 5.3.8 se conserva en vendor con su licencia MIT para que los ejercicios funcionen sin depender de un CDN.
